# MuySimpleRecycleScroll

A simple recycle scroll based on Unity ScollRect.
It's a bit costy then others(which have their own scroller).
But mine should be much simpler.

Basic functionalities provided:
- Recycle scroll
- Add/Remove single item
- Jump to specify item
- Scrollbar (For OneDirScroll, the scollbar wont linearly scroll the content)
